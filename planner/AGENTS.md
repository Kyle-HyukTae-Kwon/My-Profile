# AGENTS.md — AI 스터디 플래너

이 폴더에서 작업하는 AI 에이전트가 따라야 할 제품 정의와 규칙입니다.

## 제품 정의 (PRD)

| 항목 | 내용 |
|---|---|
| **문제** | 시험 범위 중 무엇을 모르는지, 얼마나 공부했는지, 시험일까지 얼마나 더 해야 하는지 한눈에 알기 어렵다. |
| **사용자** | 외환전문역 2종 같은 자격시험을 앞두고, 강의노트나 출제기준 PDF로 공부하는 대학생. |
| **핵심 기능** | ① 시험명·시험일·시험 범위 PDF를 넣으면 AI가 과목별 개념 체크리스트(문항·배점, 페이지 범위 포함)를 만든다.<br>② 개념마다 이해도(1~5점)를 매기고, 타이머로 공부 시간을 재고, 완료를 체크하고, 메모를 남긴다.<br>③ 이해도와 공부 시간으로 남은 필요 시간과 D-day까지 하루 평균 필요 시간을 계산한다. |
| **만들지 않을 것** | 로그인, 알림, 친구 공유, 캘린더 연동. |
| **성공 기준** | 시험 범위 PDF를 넣으면 시험명, 과목별 개념, 숙련도 체크리스트가 바로 나온다. 같은 형식이 다른 시험 PDF에도 그대로 적용된다. |

PRD에 없는 기능은 사용자에게 먼저 묻고 추가합니다. 특히 "만들지 않을 것"에 있는 기능은 만들지 않습니다.

## 규칙

### 1. 파일은 `index.html` 하나
- HTML, CSS, JavaScript를 모두 `index.html` 안에 넣습니다. 별도 `.css`, `.js`, 데이터 파일을 만들지 않습니다.
- 외부 라이브러리가 꼭 필요하면 `cdnjs.cloudflare.com`에서 버전을 정확히 적어 불러옵니다(예: PDF 읽기용 `pdf.js/3.11.174`).
- 특정 시험 내용(과목·개념 목록)을 코드에 미리 넣지 않습니다. 처음 화면은 비어 있고, 내용은 PDF로만 채웁니다.

### 2. 흰 배경에 하늘색 포인트
- 배경은 흰색, 강조색(버튼, 진행 막대, D-day 숫자 등)은 하늘색 계열을 씁니다.
- 색은 `:root`의 CSS 변수로 한곳에서 정하고, 화면 곳곳에 색 코드를 직접 쓰지 않습니다.
- 이해도 1~5점 색(빨강→초록)과 삭제 버튼의 빨강처럼 뜻이 있는 색은 강조색과 따로 둡니다.
- 하늘색 위 글자는 잘 읽히는지(명도 대비) 확인합니다.

### 3. 설명은 비전공자도 알게 쉽게
- 화면 문구, 안내, 오류 메시지는 개발 용어 없이 씁니다. 예: "localStorage에 저장" 대신 "이 브라우저에 저장".
- 오류 메시지는 무엇이 잘못됐고 어떻게 하면 되는지를 함께 알려 줍니다.
- 사용자에게 작업 결과를 설명할 때도 같은 기준을 지킵니다. 무엇이 바뀌었고, 사용자가 무엇을 하면 되는지를 짧게 씁니다.

## 구조 메모

- **실행 위치:** `index.html`은 claude.ai 아티팩트로 게시해서 씁니다.
  - 게시 규칙상 파일에 `<!doctype>`, `<html>`, `<head>`, `<body>` 태그를 넣지 않습니다. 맨 위에는 `<title>`과 `<style>`로 시작합니다.
  - 고친 뒤에는 같은 링크로 다시 게시합니다: https://claude.ai/artifact/FmQtVxSaGY78PB6acMo8Hs
- **사용하는 기능:** `sample`(AI 정리), `db`(내 계정에 기록 저장), `user`(내 저장 공간 찾기).
  - 내 컴퓨터에서 파일로 열면 AI 정리는 동작하지 않습니다. 기록은 그 브라우저에만 저장됩니다.
- **게시된 페이지의 제약:** `alert()`·`confirm()` 창과 파일 내려받기 링크가 동작하지 않습니다. 삭제처럼 되돌릴 수 없는 동작은 "두 번 눌러 실행"으로 만듭니다.
- **확인 방법:** 고친 뒤에는 아래를 확인합니다.
  - 빈 화면
  - PDF → 미리보기 → 적용
  - 이해도·타이머·완료 체크·메모
  - D-day 계산
